# 電小二微型電動車庫存系統（Volt Buddy）

正式營運資料儲存在 Supabase。桌面版提供供應商、進貨、報價、保固與送修操作；手機版僅顯示月銷量。登入後若雲端讀取失敗，畫面使用本機快取唯讀顯示，不應將舊資料寫回雲端。

## 啟用與備份

- 營運資料以雲端（Supabase）為準。網頁上的「匯出備份」只下載 JSON 供查看與核對，**無法還原回雲端**。
- Supabase 免費方案沒有自動備份：店長應每週執行 `bash scripts/backup-db.sh` 備份資料庫，月底結帳與分紅計算前再各做一次。安裝、備份與還原步驟見 [雲端資料庫備份與還原](docs/database-backup.md)。
- 備份檔含客戶與登入帳號資料，請存放在受保護的位置；不要將備份或登入資料提交到 Git。
- 供應商與進貨僅限店長；報價與保固依登入角色顯示可用操作。手機端不提供這些管理頁面。

## 上線驗收

1. 店長在桌面版建立供應商與進貨單，收貨後確認庫存只增加一次。
2. 用第二個已授權帳號在另一台裝置重新登入，確認庫存、報價與保固資料一致。
3. 確認店員無法進入供應商與進貨頁面，也無法透過雲端 API 執行店長操作。
4. 確認手機登入後只有月銷量頁面可用。
