# 出保固（免費更換）

使用前先匯出備份；資料仍保存在目前瀏覽器，請使用單一分頁。

1. 店長登入後，在「庫存管理 → 登記庫存異動」選擇換出品項。
2. 異動類型選「出保固（免費更換）」，選擇原保固紀錄，確認客戶與沿用到期日。
3. 輸入換出數量與更換原因。機車／電池必須補齊在庫序號，再選擇等量的換出序號。
4. 按「記錄異動」。成功才會扣庫存；儲存失敗會保留輸入，請確認錯誤後重試。
5. 到「保固管理」查看原保固的「出保固更換紀錄」。可用換出序號搜尋原保固。

更換紀錄保存當下成本、操作帳號、時間、數量與換出序號。更換品沿用當時原保固到期日，不建立新保固或銷售，也不調整月銷售利潤。原保固已到期時會顯示提示，由店長判斷是否仍提供免費更換。

故障品不會自動回收入庫；原銷售與序號歷史保留。已出保固的序號不能再次售出；有更換紀錄的品項、客戶與原保固不可刪除。更換紀錄與成本快照會隨整體備份保存。
